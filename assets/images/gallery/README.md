# Galéria Képek Útmutató

## Képméretek
- Szélesség: 800-1200px
- Magasság: 600-900px (4:3 vagy 3:2 arány ajánlott)
- Formátum: JPG vagy WebP
- Minőség: Közép-magas (80-90%)

## Mappa struktúra

### `/eskuvo/` - Esküvői képek (7 kép)
- `eskuvo-1.jpg` - Esküvői ceremónia teraszon panorámával
- `eskuvo-2.jpg` - Esküvői asztaldekoráció gyertyákkal
- `eskuvo-3.jpg` - Násznép csoport fotó teraszon
- `eskuvo-4.jpg` - Esküvői torta virágokkal díszítve
- `eskuvo-5.jpg` - Első tánc este a násznépnek
- `eskuvo-6.jpg` - Esküvői terítés elegáns díszekkel
- `eskuvo-7.jpg` - Menyasszonyi csokor részlet
- `eskuvo-8.jpg` - Esküvői helyszín napnyugtakor

### `/lanykeres/` - Lánykérés képek
- `lanykeres-1.jpg` - Romantikus helyszín
- `lanykeres-2.jpg` - Dekoráció részlet
- `lanykeres-3.jpg` - Terasz panoráma
- `lanykeres-4.jpg` - Asztaldekoráció
- `lanykeres-5.jpg` - Gyertyás atmoszféra
- `lanykeres-6.jpg` - Gyűrű/ajándék részlet

### `/csapatepites/` - Csapatépítő képek
- `csapatepites-1.jpg` - Csapatépítő program
- `csapatepites-2.jpg` - Outdoor terület
- `csapatepites-3.jpg` - Workshop/előadás
- `csapatepites-4.jpg` - Catering
- `csapatepites-5.jpg` - Csapat együtt
- `csapatepites-6.jpg` - Természeti környezet

### `/ceges/` - Céges rendezvény képek
- `ceges-1.jpg` - Konferencia terem
- `ceges-2.jpg` - Üzleti találkozó
- `ceges-3.jpg` - Prezentáció
- `ceges-4.jpg` - Üzleti ebéd
- `ceges-5.jpg` - Networking
- `ceges-6.jpg` - Technikai felszereltség

**Megjegyzés:** A születésnap és családi összejövetel oldalaknak nincs galéria szekciójuk, ezért nem igényelnek külön képeket.

## Képek feltöltése után
1. Nevezd el a képeket a fenti séma szerint
2. Másold be őket a megfelelő mappába
3. A weboldal automatikusan betölti őket
4. Ellenőrizd minden oldalt, hogy megfelelően jelennek-e meg

## Placeholder képek
Jelenleg a galéria képek külső URL-ekre mutatnak. Ha szeretnéd lecserélni őket:
1. Tölts fel képeket a megfelelő mappákba
2. A HTML fájlokban az URL-ek már a helyi útvonalakra mutatnak
